# namasdev.Data.en

Generic repository-pattern interfaces (read-only and read/write) for data access, with soft-delete, paging/ordering, and flexible property-loading overloads. Interface-only — implementations live in `namasdev.Data.Entity.en` (EF6) and `namasdev.Data.EntityCore.en` (EF Core).

## Install

```
dotnet add package namasdev.Data.en --prerelease
```

## Target frameworks

`net48`, `net9.0`
